# 学习记录 · Study Log

A tiny self-hosted study journal. Zero dependencies — one Node file, one SQLite file, opens in your browser.

小到可以放在文件夹里带走的学习记录工具：长期目标 → 每日打卡 → 卡点沉淀。不联网、不注册、不依赖任何 npm 包，数据就是一个 `.db` 文件。

界面中英双语，右上角一键切换；页脚 18 句中英对照，每 8 秒换一句。

## 它是什么

一本给自己看的学习日志，只记四件事：

1. **要去哪** —— 长期目标，可拆一层小目标，各自有里程碑
2. **今天做了什么** —— 打卡 + 两三行记录，数量也能记（背了 40 个单词）
3. **接下来几天干什么** —— 未来 7 天，每天一句话，随手改
4. **卡在哪** —— 卡点单独记，解决时写下怎么绕过去的，越攒越像自己的排错手册

设计上刻意做了几个取舍：

- **不要百分比**。里程碑勾得动才算数，填 67% 是自我欺骗
- **打卡和日记分开**。打钩自动记下，正文只写计划之外的事，避免重复录入
- **卡点独立成表**。写在日记里第二天就被盖住了，它应该是能跨天滚动的资产
- **漏了不算失败**。没打卡的日子标黄，点进去就能补，不标红

## 快速开始

需要 Node.js 22.5 以上（用到内置的 `node:sqlite`）。推荐 22 LTS 或更新。

```bash
node server.mjs
```

或者 Windows 下双击 `run.cmd`，它会自动启动并打开浏览器。想关掉双击 `stop.cmd`。

然后访问 http://localhost:4321

首次启动是空白状态。想先看看长什么样：

```bash
node server.mjs --seed
```

会写入一份示例数据（中文），删掉 `data.db` 即可重来。

## 页面

| 路径 | 作用 |
| --- | --- |
| `/` | 今日：打卡、日记、里程碑、卡点；看过去某天就加 `?d=2025-10-29` |
| `/plan` | 未来 7 天，每天一句话，改完自动保存 |
| `/goals` | 所有目标、里程碑、打卡任务；拖 `⠿` 调顺序 |
| `/goal/:id` | 单个目标的详情（含它的小目标） |
| `/blockers` | 卡点总览，按目标分组；已解决的能重新打开 |
| `/timeline` | 70 天热力图 + 最近日记，漏打卡的日子标黄 |
| `/help` | 应用内的使用说明 |
| `/export?days=7` | 导出 Markdown（末尾附一段复盘提问），`days` 可改 1–365 |

## 会遇到的几件事

- **打钩即时生效**，不用点保存；失败会回滚并提示，不会「看着存上了其实没存」
- **每周 N 次**的任务会显示「本周 2/3」，达标变绿
- **完成目标要确认一次**：先列出还剩几个里程碑、几个任务会被暂停、几个卡点没解决，再点「确认」
- **完成后任务自动暂停**，想继续就去 `/goals` 侧栏「已暂停」里恢复；判断错了点「重新开始」
- **删目标也一样两段确认**，会明确告诉你多少里程碑、任务、卡点受影响；只是做完了别用删
- **未来 7 天**那页和首页「明天的第一件事」是同一份数据，改哪边都一样
- `Ctrl/Cmd + S` 存日记；`Tab` 到目标把手后用 `↑ ↓` 也能调顺序

## 加一种语言

目前只有中文和英文，作者不会再加。想加别的语言，改 `i18n.mjs` 就行：

1. 复制 `S.zh` 整个对象，改 key 名（比如 `ja`）
2. 逐条翻译
3. 在 `views.mjs` 的语言切换按钮里加一项

没有用到任何 i18n 库，就是一个对象查表，加语言不需要动别的代码。

## 已知限制

- 只支持中英；右到左语言（阿拉伯语、希伯来语）需要额外改 CSS
- 数字没有做本地化（千分位、日期顺序都保持简单格式）
- 单用户设计，没有账号体系
- 手机上能看能点，但拖动排序不响应触摸，所以窄屏自动换成 `↑ ↓` 按钮
- 局域网外访问需要自己搭隧道或部署到服务器

## 安全

默认没有登录，**只适合放在自己的电脑或家里局域网**。为此做了这些：

- 拒绝跨站提交（`Origin` / `Referer` 对不上就 403），别人打开的网页没法偷偷改你的记录
- `Host` 只接受 localhost、IP、本机名，挡掉 DNS rebinding
- 请求体上限 512 KB，标题等长文本有长度上限
- 页面带 `Content-Security-Policy`，脚本只能来自本站
- 出错只回一个错误编号，堆栈留在终端里

## 可选：口令保护

如果要放到公网，**务必**加口令，否则任何人拿到地址都能翻你的日记。

```bash
APP_PASSWORD=你的长口令 node server.mjs
```

或者在同目录建一个 `password.txt` 写入口令（配合 `run.cmd` 双击启动）。设了口令后未登录一律跳转登录页，同一 IP 连错 10 次锁 10 分钟。

还有一种更省事的方式：在 `secret.txt` 里写一串随机字符，启动后必须访问 `/s/<那串字符>` 才能进入，直接访问根路径返回 404。
